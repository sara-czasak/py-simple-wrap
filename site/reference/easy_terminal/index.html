    Easy Terminal

    py_simple.easy_terminal

    easy_terminal is meant to make it easy to get styled output in the terminal. Built on top of the rich library — no more memorizing markup strings.

    EasyTerminal

    Builds styled terminal text by chaining style methods, then prints it.

    Nothing is printed until show() is called, so you can chain as many styles as you like first. Every set_* method returns the object itself, which is what makes the chaining work.

    Parameters:

    Name Type Description Default
    text str

    The text to print.

    		 required
    Example 
    from py_simple import EasyTerminal

EasyTerminal("Hello World").set_color("red").set_bold().show()

    from rich.console import Console

console = Console()
console.print("Hello World", style="bold red")

    set_bg_color(color)

    Sets the background color and returns the object for chaining.

    Parameters:

    Name Type Description Default
    color str

    A color name ("blue"), a hex code ("#0000ff"), or an rgb string ("rgb(0,0,255)").

    		 required

    Returns:

    Name Type Description
    EasyTerminal EasyTerminal

    The same object, ready for the next call.
    Example 
    from py_simple import EasyTerminal

EasyTerminal("Hello").set_color("white").set_bg_color("blue").show()

    from rich.console import Console

console = Console()
console.print("Hello", style="white on blue")

    set_bold()

    Makes the text bold and returns the object for chaining.

    Replaces any weight set earlier, so calling set_bold() after set_light_weight() leaves the text bold, not both.

    Returns:

    Name Type Description
    EasyTerminal EasyTerminal

    The same object, ready for the next call.
    Example 
    from py_simple import EasyTerminal

EasyTerminal("Hello").set_bold().show()

    from rich.console import Console

console = Console()
console.print("Hello", style="bold")

    set_color(color)

    Sets the text color and returns the object so you can keep chaining.

    Parameters:

    Name Type Description Default
    color str

    A color name ("red"), a hex code ("#ff0000"), or an rgb string ("rgb(255,0,0)").

    		 required

    Returns:

    Name Type Description
    EasyTerminal EasyTerminal

    The same object, ready for the next call.
    Example 
    from py_simple import EasyTerminal

EasyTerminal("Hello").set_color("#ff0000").show()

    from rich.console import Console

console = Console()
console.print("Hello", style="#ff0000")

    set_light_weight()

    Makes the text dim (lighter than normal) and returns the object.

    Terminals only have bold, normal and dim, so this is the lightest weight available. It replaces any weight set earlier.

    Returns:

    Name Type Description
    EasyTerminal EasyTerminal

    The same object, ready for the next call.
    Example 
    from py_simple import EasyTerminal

EasyTerminal("Hello").set_light_weight().show()

    from rich.console import Console

console = Console()
console.print("Hello", style="dim")

    show()

    Prints the text to the terminal with all the chosen styles.

    Call this last. Anything you didn't set falls back to the terminal's normal look (the text color defaults to white).

    Example 
    from py_simple import EasyTerminal

EasyTerminal("Hello World").set_color("red").set_bg_color("white").set_bold().show()

    from rich.console import Console

console = Console()
console.print("Hello World", style="bold red on white")

    print_centered(text, width=None)

    Prints text centered across the terminal width.

    A one-line way to center a heading or message without working out the padding yourself. When no width is given, the current terminal width is used.

    Parameters:

    Name Type Description Default
    text str

    The text to print.

    		 required
    width int

    Width to center within. Defaults to the current terminal width.

    		 None
    Example 
    from py_simple import print_centered

print_centered("Hello World")

    from rich.align import Align
from rich.console import Console

Console().print(Align.center("Hello World"))

    print_rule(title='')

    Print a horizontal divider with an optional centered heading.

    Uses the current console width. Rich fits or shortens the heading when the console is narrow; the exact divider depends on the console.

    Parameters:

    Name Type Description Default
    title str

    Heading to show as literal text, without interpreting Rich markup. Defaults to an empty string for a plain divider. Values are converted to strings, as with print_centered().

    		 ''
    Example 
    from py_simple import print_rule

print_rule("Results")

    from rich.console import Console
from rich.text import Text

Console().rule(Text("Results"))

    print_styled(text, color='#ffffff', bg_color=None, bold=False, dim=False)

    Prints styled text to the terminal in a single function call.

    Parameters:

    Name Type Description Default
    text str

    The text to print.

    		 required
    color str

    Text color name ("red"), hex code ("#ff0000"), or rgb string ("rgb(255,0,0)"). Defaults to "#ffffff".

    		 '#ffffff'
    bg_color str

    Background color name ("blue"), hex code ("#0000ff"), or rgb string. Defaults to None.

    		 None
    bold bool

    Whether to make the text bold. Defaults to False. If both bold and dim are True, bold takes precedence.

    		 False
    dim bool

    Whether to make the text dim (light weight). Defaults to False. Ignored if bold is also True.

    		 False
    Example 
    from py_simple import print_styled

print_styled("Hello World", color="red", bg_color="white", bold=True)

    from rich.console import Console

console = Console()
console.print("Hello World", style="bold red on white")
