    Easy Converter

    py_simple.easy_converter

    easy_converter is built to simplify different types of conversions

    celsius_to_fahrenheit(temp_celsius)

    Converts temperature in Celsius to temperature in Fahrenheit. Returns degrees Fahrenheit as float.

    Parameters:

    Name Type Description Default
    temp_celsius float

    Temperature in Celsius.

    		 required

    Returns:

    Name Type Description
    float float

    The equivalent temperature in Fahrenheit.
    Example 
    from py_simple import celsius_to_fahrenheit

temp_f = celsius_to_fahrenheit(25)  # -> 77.0

    celsius = 25
fahrenheit = (celsius * 9 / 5) + 32

    fluid_oz_to_ml(oz, standard='us')

    Converts fluid ounces to milliliters. Returns milliliters as a float.

    Parameters:

    Name Type Description Default
    oz float

    Fluid ounces.

    		 required
    standard str

    Measurement standard, 'us' or 'uk'. Defaults to 'us'.

    		 'us'

    Returns:

    Type Description
    float | None

    float | None: The equivalent volume in milliliters, or None if standard isn't 'us' or 'uk'.
    Example 
    from py_simple import fluid_oz_to_ml

ml_us = fluid_oz_to_ml(1, standard='us')  # -> 29.6
ml_uk = fluid_oz_to_ml(1, standard='uk')  # -> 28.4

    oz = 1
ml_us = round(oz * 29.6, 2)
ml_uk = round(oz * 28.4, 2)

    hh_mm_ss_to_seconds(hours=0, minutes=0, seconds=0)

    Returns hours, minutes and seconds converted to seconds.

    Parameters:

    Name Type Description Default
    hours int

    Number of hours to convert. Defaults to 0.

    		 0
    minutes int

    Number of minutes to convert. Defaults to 0.

    		 0
    seconds int

    Number of seconds to convert. Defaults to 0.

    		 0

    Returns:

    Name Type Description
    int int

    The total number of seconds.
    Example 
    from py_simple import hh_mm_ss_to_seconds

total = hh_mm_ss_to_seconds(1, 1, 1)  # -> 3661

    hours, minutes, seconds = 1, 1, 1
total = (hours * 3600) + (minutes * 60) + seconds

    seconds_to_hh_mm_ss(seconds)

    Returns seconds in HH:MM:SS format.

    Parameters:

    Name Type Description Default
    seconds int

    Number of seconds to convert.

    		 required

    Returns:

    Name Type Description
    str str

    Time formatted as HH:MM:SS.
    Example 
    from py_simple import seconds_to_hh_mm_ss

time_string = seconds_to_hh_mm_ss(3665)  # -> "01:01:05"

    seconds = 3665
hours = seconds // 3600
minutes = (seconds % 3600) // 60
secs = seconds % 60
time_string = f"{hours:02}:{minutes:02}:{secs:02}"
