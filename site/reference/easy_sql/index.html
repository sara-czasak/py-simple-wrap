    list_tables(connection, cursor)

    Lists the user tables in a SQLite database.

    Skips SQLite's own internal tables (names starting with sqlite_) so the result is the tables you created.

    Parameters:

    Name Type Description Default
    connection Connection

    Open connection to the database.

    		 required
    cursor Cursor

    Cursor for executing SQL statements.

    		 required

    Returns:

    Type Description
    list[str]

    list[str]: Table names, sorted by name. An empty list means the database has no user tables yet.

    Raises:

    Type Description
    EasySqlError

    If the cursor does not belong to the connection, or if the query cannot be run.
    Example 
    from py_simple import list_tables, open_db

connection, cursor = open_db("notes.db")
print(list_tables(connection, cursor))

    import sqlite3

connection = sqlite3.connect("notes.db")
cursor = connection.cursor()
cursor.execute(
    "SELECT name FROM sqlite_master "
    "WHERE type = 'table' AND name NOT GLOB 'sqlite_*' "
    "ORDER BY name"
)
print([row[0] for row in cursor.fetchall()])
