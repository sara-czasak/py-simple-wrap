    py-simple-wrap

    Making Python feel like plain English.


    py-simple-wrap is a beginner-friendly Python toolbox — simple, intuitive functions for common tasks, so you can build something fun before the syntax gets in the way.

    🐍 Python Compatibility

    py-simple-wrap v0.9.0+ requires Python 3.11 or newer.

    Supported versions: Python 3.11, 3.12, 3.13, and 3.14.

    ⚠️ Python 3.10 support has been discontinued due to security vulnerabilities affecting Pillow, a dependency used by the image utilities.

    If you're using Python 3.10, please upgrade to a supported version before installing v0.9.0 or later.

    For more details, see our Security Policy.


    pip install py-simple-wrap

    This installs the lightweight core; a few modules need extra packages — see Installation in the Quickstart for the full list.

    from py_simple import make_blank_file, miles_to_km, is_valid_email

make_blank_file("notes","txt")
print(miles_to_km(26.2))  # 42.16...
print(is_valid_email("hello@example.com"))  # True

    Full walkthrough in QUICKSTART.md, or browse the documentation site.


    😰 → 😎 See the difference

    The traditional way 

    import requests
from bs4 import BeautifulSoup

try:
    response = requests.get("https://github.com", timeout=10)
    response.raise_for_status()
    page = BeautifulSoup(response.content, "html.parser")
    title = page.title.string
except Exception as e:
    print("The site is down or address is invalid.")

    The py-simple-wrap way

    Needs the [web] extra: pip install py-simple-wrap[web]

    from py_simple import get_page_title

print(get_page_title("https://github.com"))
